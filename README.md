# Vtools

## Features

- Via fencing along selected tracks, arcs and pads.
- Via stitching inside selected zones.

## Installation

1) Download the [latest release ZIP file](https://github.com/NBalciunas/kicad-vtools/releases).
2) Open KiCad and in the main window click on "Plugin and Content Manager".
3) Click "Install from File..." and select the downloaded ZIP file.  
4) Restart KiCad. The plugin is now installed.
